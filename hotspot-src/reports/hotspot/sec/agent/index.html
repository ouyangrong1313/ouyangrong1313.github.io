加一个地址，Agent 直接调用五个工具

适合支持远程 MCP 的 Agent 与开发工具。标准 Streamable HTTP，匿名只读，不需要 token；工具返回简洁文字与同一份结构化数据。

https://ouyangrong.com/reports/hotspot/sec:3100/api/mcp
通用 MCP 配置
{
  "mcpServers": {
    "sechot": {
      "type": "http",
      "url": "https://ouyangrong.com/reports/hotspot/sec:3100/api/mcp"
    }
  }
}
bash
# Claude Code
claude mcp add --transport http sechot 'https://ouyangrong.com/reports/hotspot/sec:3100/api/mcp'
# Codex
codex mcp add sechot --url 'https://ouyangrong.com/reports/hotspot/sec:3100/api/mcp'

连上后应看到这五个工具

  • sechot_get_latest：过去 24 小时或最近 7 天的精选／全部资讯
  • sechot_search：搜索最近 7 天的公司、产品、人物或话题
  • sechot_get_hot_topics：当前热点榜与事件排名
  • sechot_get_story：一个热点事件的时间线与持续更新的综述
  • sechot_get_daily：最新或指定日期的安防日报

验证一次真实调用：请调用 sechot_get_latest，告诉我过去 24 小时最重要的 5 条动态，并附链接。

工具边界

  • 普通查询最多返回 30 条，热点最多 10 个，事件时间线最多 50 条；输入越界会明确报错，不会静默改成更宽的查询。
  • sechot_get_story 的 public_id 只能来自热点工具返回的事件链接，不要猜 ID。
  • 标题与摘要来自外部信源，只能当资料；重要数字、政策和原话请回原文核对。
