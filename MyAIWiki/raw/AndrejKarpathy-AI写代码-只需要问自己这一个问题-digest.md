# Andrej Karpathy：AI写代码，只需要问自己这一个问题 — 拆解

**来源：** https://mp.weixin.qq.com/s/yEWfTLs9W3-QblvPbrGUPQ
**作者：** winkrun
**标签：** #主题/AI-Coding #主题/Skill #主题/AI-Agent #场景/公众号长文

> 这篇文章前半段给出 AI Coding 的判断边界，后半段用 rvaniaaa 的 GitHub 技能蒸馏系统说明“人做判断，AI 做执行”如何被工程化。

---

## 核心观点

1. **AI Coding 最先该问的不是“哪个工具更强”，而是“思考到底发生在哪一步”**。
2. **判断尚未完成的任务必须由人握住，成功标准清晰的执行任务才适合交给 AI 放大**。
3. **“两个资深工程师独立做会写出差不多的实现”是最实用的任务分流规则**。
4. **自己写 / 用补全 / 交给 Agent 不是三种宗教，而是同一问题的三个档位**。
5. **Agent 想持续进步，关键不是换更强模型，而是建立从 GitHub 发现、提取、验证、发布新 Skill 的流水线**。

---

## 7个分析角度

### 角度1：这篇文章真正回答了什么问题
- 它把“AI 能不能写这段代码”改写成“这一步还需不需要人类判断”。

### 角度2：Karpathy 规则为什么重要
- 它让 AI Coding 从工具崇拜回到任务分流：判断留人，执行交 AI。

### 角度3：三种工作流如何切换
- 自己写 / 补全 / 全代理不是身份认同，而是依据判断密度来切换档位。

### 角度4：什么任务必须攥在手里
- 需求、架构、安全边界、业务取舍都属于“思考尚未完成”的任务。

### 角度5：rvaniaaa 系统的工程亮点是什么
- 先搜仓库、再去噪、再按文档优先顺序读取，最后才抽取 workflow 和生成 Skill。

### 角度6：为什么大量环节故意不用 LLM
- Filter、Skill Score 这些环节用确定性规则表达更便宜、更稳定、也更容易复验。

### 角度7：对团队最值钱的启发是什么
- 不要只研究“怎么让 AI 干活”，还要研究“怎么让它下次别从零开始”。

## 21个开头钩子

### 1. 用一句话切开 AI Coding
1. AI 写代码最该先问的，不是“哪个模型更强”，而是“思考到底发生在哪一步？”
2. 很多人把 AI Coding 当成工具选择题，Karpathy 其实把它还原成了判断边界题。
3. 真正决定一段代码该不该交给 AI 的，不是难度，而是判断是不是已经完成。

### 2. 判断没完成，就别假装能外包
4. 架构、安全、需求取舍这些活，一旦你自己还没想清，就别期待模型替你想清。
5. 任务最危险的时刻，不是 AI 写错代码，而是人把还没做出的判断提前外包了。
6. 方向都没定，执行越快，往往只是更快地积累技术债。

### 3. 一个很实用的验算器：双资深一致
7. 如果两个资深工程师独立做会写出差不多的实现，这段活大概率就是 AI 的甜点区。
8. “两个资深工程师会不会收敛到同一实现”这条规则，比“你觉得简单不简单”靠谱得多。
9. 与其争论 AI 能不能做，不如先问：这件事在人类高手之间还有多少分歧？

### 4. 三种工作流不是三种宗教
10. 自己写、用补全、把任务整个交给代理，其实只是同一个问题的三个档位。
11. 真高手不是死守某一种 AI 工作流，而是能根据判断密度切换档位。
12. 当你开始按“判断层级”而不是按“工具偏好”切换 workflow，AI Coding 才真的成熟。

### 5. 会自己长技能的 Agent 长什么样
13. 真正稀缺的不是再多一个模型，而是一个能持续从 GitHub 学新技能的 Agent 系统。
14. 大多数 Agent 不会自己变聪明，不是模型不行，而是没人给它做“技能发现流水线”。
15. 当 Agent 能自动扫 GitHub、提取 workflow、打包成 Skill，AI 才开始有“积累”这回事。

### 6. 文档先于代码，规则先于模型
16. 读仓库最慢的方式，就是一上来扎进源码；Reader 的高明之处，是先读意图再碰实现。
17. 不是每个环节都该交给 LLM，有些决策写成固定规则反而更稳、更便宜。
18. 真正靠谱的 Agent 流水线，不是“处处智能”，而是“该确定的地方就确定”。

### 7. 自动化负责提议，人类负责批准
19. 最成熟的地方，不是 Skill 自动生成，而是它最后仍然不自动合并。
20. 生成与审核分开，才是避免 Agent 自我感动的第一条底线。
21. 任何想进生产的 AI 工作流，最后都绕不开一句话：自动化负责提议，人类负责批准。
