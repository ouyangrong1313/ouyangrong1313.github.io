## 一句话总结

**企业让 Agent 长期稳定完成有价值任务 = 架构线 + 业务线 + 组织线 三线合一 —— Agent 是企业软件的"认知与行动层",Coding Agent 是早期优势场景,Workflow/Agent/Knowledge 三选一靠决策矩阵,人才招聘看 4 维度**。

## 核心观点(8 条)

1. **企业软件三层架构**:用户入口与交互层 + 认知与行动层(Agent)+ 业务记录层(CRM/ERP)—— Agent 是新增的中间层,不是替代层
2. **Agent 价值的双指标**:完成多少任务 + 完成任务有多大价值 —— 不是聊天次数 / 工具调用次数 / 生成内容长度
3. **Coding Agent 是早期优势场景**:上下文清晰 + 工具天然 + 验证机制完整 + 恢复成本低(4 特征) —— Manus 用 CodeAct 思路,Codex / Claude Code 扩大任务范围
4. **Workflow vs Agent 决策矩阵**:横轴=业务知识专业程度 / 纵轴=工具数量行动次数循环推理;4 象限分别对应 Workflow / 知识工程 / 通用 Agent / 业务型 Agent
5. **Agent 产品形态 2 选 1**:垂直能力嵌入成熟产品(CRM 分析/客服建议)/ 通用能力做成独立 Agent 产品(Web/桌面端/CLI 三入口)
6. **企业 AI 转型 4 阶段**:单点试用(个人)→ 工具集中(平台化)→ 多 Agent 协作(跨系统)→ AI 原生组织(流程重构)
7. **AI 原生组织 3 变化**:取消中层(决策权前移)/ 评价体系从过程转结果 / 跨部门沟通由 AI 代理
8. **Agent 人才招聘 4 维度**:基础素质(聪明/乐观/皮实/自省)/ 专业能力(P5-P9)/ 业务能力(谁在赚钱/链路如何)/ 组织能力(冲突处理/预期管理)

## 关键决策矩阵

### Workflow vs Agent 决策

| 业务知识专业度 ↓ / 行动复杂度 → | 低行动次数 | 高行动次数 |
|---|---|---|
| 通用业务 | 自动化脚本 | **通用 Agent**(Deep Research / Coding Agent / WorkBuddy) |
| 专业业务 | **知识工程**(本体 + Skill + 知识图谱) | **业务型 Agent**(金融 / 法律 / 医疗 / 客服) |

> 注:固定流程且异常少的任务优先 Workflow,不进入决策矩阵(直接归 Workflow)

### 企业 AI 转型 4 阶段

| 阶段 | 特征 | 提效主体 | Seetong 自评(待补) |
|---|---|---|---|
| 1. 单点试用 | 个人用 ChatGPT / Copilot | 个人 | 2024-2025 阶段(已完成) |
| 2. 工具集中 | 内部 AI 平台 + 知识库 + Skill 管理 | 团队 | **当前阶段**(2026 H1) |
| 3. 多 Agent 协作 | 跨系统任务 + 业务 Agent 协作 | 跨部门 | 待规划 |
| 4. AI 原生组织 | 流程重构 + 人 Agent 协作 | 组织 | 远期目标 |

### Agent 人才招聘 4 维度

| 维度 | 关键词 | 评估方法 |
|---|---|---|
| 基础素质 | 聪明 / 乐观 / 皮实 / 自省 | 学习速度 / 投入意愿 / 失败恢复 / 复盘能力 |
| 专业能力 | P5-P9 级别 | 负责功能 → 模块 → 产品 → 产品线 → 创造业务 |
| 业务能力 | 谁在赚钱 / 链路如何 / 哪些共性 | 行业理解 + 商业化意识 |
| 组织能力 | 冲突 / 资源 / 预期 | 跨部门协作 + 预期管理 |

## 核心金句(5 条)

1. "Agent 增加了一个新的软件层:认知与行动层。"
2. "Coding Agent 提供了一个适合模型持续行动的环境:上下文清晰、工具丰富、结果可验证、过程可反馈、错误可恢复。"
3. "表面上看,我们讨论了 Agent 框架、架构、Tool、Skill、Pipeline、多 Agent、AI 原生组织和人才要求,背后始终围绕着一件事:**企业怎样让 Agent 长期、稳定地完成有价值的任务**。"
4. "Agent 领域目前还没有形成特别稳定的产品和技术范式,大多数人也缺少完全匹配的项目经验。"
5. "生产级 Agent 最终会走向一个完整闭环:先找到值得解决的业务问题,再搭建可以持续交付的系统,随后把实践经验沉淀为 Tool、Skill、Pipeline 和评测集,最后形成组织可以反复使用的生产能力。"
