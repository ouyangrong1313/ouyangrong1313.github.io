## 一句话总结

工作有 README，人生也该有一份——两份高 star 开源指南（HowToLiveBetter 的 614 条生活建议、byoungd/up 的人生进阶方法论）把健康、租房、维权、学习、AI 协作这类"吃亏才补课"的常识，变成遇事能查、按性价比排序的可检索清单。

## 核心观点

1. **常识缺口是普遍的**——我们花大量时间学怎么工作，却很少认真学过怎么照顾自己、处理生活里的麻烦（健康、租房合同、外包业务、离职权益）。
2. **"等以后"是默认失败模式**——每次感慨都暗暗提醒自己，但过几天又回到熟悉节奏；感慨不解决问题，清单才能。
3. **"人生 README"= 可检索的遇事入口**——不要求背下来，只要求遇到事时知道"先查什么、从哪里下手"，除了硬撑还有第二选择。
4. **性价比排序是关键设计**——HowToLiveBetter 每节内条目按性价比从高到低排列，先读高性价比项，投入产出比最优。
5. **两份指南互补**——HowToLiveBetter 给"生活常识清单"，byoungd/up 给"成长方法论"（发现问题 → 主动学习 → 与 AI 协作 → 完成真实任务 → 保存证据 → 复盘迁移）。
