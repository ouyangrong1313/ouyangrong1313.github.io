# AI 什么都能写和重写 — Digest

## 一句话总结

> **"AI 什么都能写,我陷入虚无主义"** — TiDB 联合创始人/CTO 黄东旭完成 db9 项目(1-2 人 / 3 个月 / 100 万行 Rust / 0 人手写 0 人手 review / 1 万个数据库实例 / 1 天 10 亿 token / 2000 美金/月),**没看到 AI 边界**;徐昊认为**代码不重要,知识才重要**;滕昱认为 **AI 讨好型人格没有痛苦反馈,只有"老登"(老工程师)能做判断掌舵**;维护之争两派分岔 — **徐昊(未来派):重写足够快就不必维护** vs **滕昱(现实派):企业屎山代码 Agent 精神分裂,部署出问题还得自己处理**。

## 技术栈锁定松动(4 大证据)

- **Bun: Zig → Rust 用 6 天**(对比 Meta Java→Kotlin 4.5 年;微软 TypeScript→Go 14 个月)
- **Mitchell Hashimoto**: "编程语言过去意味着锁定,但现在越来越不是这样了"
- **中型企业 iOS/Android 原生 → React Native**: "即使后来证明决策是错的,未来也可以再用 Agent 迁回原生"
- **Agent 视角**:MySQL vs Postgres = 方言问题,不是世界观问题;Agent 无品味之争,只在乎"接口稳定/语义清楚/生态完备/文档丰富"

## 8 个核心命题(原文)

1. **db9 100 万行 1-2 人 0 人手写** — 黄东旭"没看到边界"
2. **技术栈锁定松动** — Bun 6 天,Agent 把选型看作方言问题
3. **"什么都能写"虚无主义** — 黄东旭"软件作为护城河这件事已经没有了"
4. **"什么都能重写"成趋势** — 4 大案例,即使没有源码也能重写
5. **代码不重要,知识才重要** — 徐昊"知识工程";真正要反向的不是代码是 specification
6. **AI 讨好型人格** — 没有痛苦反馈,会编答案,会忽悠,测试也能造假
7. **"老登"说了算** — 90-95% 程序员受影响,老工程师做判断掌舵
8. **企业软件维护之争** — 徐昊(未来派)vs 滕昱(现实派),两派分岔
