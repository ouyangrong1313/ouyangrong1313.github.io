# 不满油管推荐算法，Karpathy用Claude2小时做了个HackerTube

**来源**：AgenticHub
**原文链接**：https://mp.weixin.qq.com/s/8flITf7_3Ie5VeqkIXgxgA
**发布时间戳**：1793618519（2026-11-03）
**获取方式**：curl + Python 清洗

---

YouTube 的推荐系统用过才知道有多拉！你刚看完一个扎实的技术讲解，它就给你推起了"10 个你必须知道的 AI 秘密""这个工具让程序员效率提升 1000%"这类标题党内容。算法优化的是点击率和停留时长，而不是内容质量和长期价值。

Karpathy 实在受不了了：

"I was annoyed with YouTube's recommendations…"

他想看的是那些被真正懂行的人反复提到、经得起时间检验的视频，而不是被流量机器筛选出来的内容。

于是周末，Karpathy 随手丢出了一个叫 HackerTube 的小项目。

https://hackertube.org/

没有登录、没有算法黑箱、没有标题党缩略图。打开就是一堆被 Hacker News 社区反复推荐了二十年的 YouTube 视频。

Karpathy 让 Claude（具体是 Claude Code + Opus 5.5）去处理了一件听起来就很折磨人的事：把 Hacker News 过去 20 年、4300 万条评论全部过了一遍，从中筛选出那些被反复推荐的 YouTube 视频。

最终结果是 6454 个视频。整个过程大约只花了 2 个小时。

他本人几乎只做了三件体力活：去 Google Cloud 申请了一个 YouTube Data API key；租了一台 VPS；买了域名。

剩下的事情——写代码、部署、加固服务器、优化前端——全交给 Claude 自己完成。他只需要在浏览器里偶尔配合一下，然后把服务器 IP 丢给 Claude，告诉它去部署、去加固、去优化。

这已经不是传统意义上的"用 AI 辅助写代码"，而是接近 AI 自己把项目从 0 到 1 做完。

几个细节很有意思：

不需要登录。状态存在本地浏览器里，打开就能用。缩略图不是标题党。它用的是视频中间真实截取的一帧，而不是创作者为了点击率精心挑选的封面。数据完全开放。底层分析数据打包成一个 zip 文件放出来了。你可以把这个数据丢给你自己的 Claude，让它按照你的口味再筛一遍，做出属于你自己的版本。还有 HackerTube Longs 的玩法暗示。

简单说，这是一个基于真实社区共识而不是平台点击优化的推荐系统。

表面上看，这只是一个周末小玩具。往深一点看，至少有三层含义。

第一，内容发现的范式在变。

过去我们依赖平台算法，现在越来越有人开始用"高质量社区的历史讨论"作为过滤器。Hacker News、Reddit 特定板块、甚至某些 Discord 频道，本质上都是经过人类注意力和时间筛选过的高质量信号源。AI 现在已经能把这些信号批量、系统地提取出来。

第二，个人软件的开发门槛在急剧下降。

以前做一个稍微像样点的 web 服务（爬数据、清洗、部署、前端），至少需要几天到几周。现在一个熟练使用 Claude Code 的人，可以在一个周末把它变成现实。Karpathy 自己也说：

"Many awesome projects that would have normally taken weeks/months even can now be few-shotted for breakfast."

"few-shotted for breakfast"——用几轮对话，在吃早餐的功夫就搞定。

这不是在吹某个模型有多强，而是在展示一种新的工作流：人类负责提出清晰意图和做关键决策，AI 负责把中间大量机械、重复、需要耐心的工作做完。

第三，数据的可复用性被重新打开。

他把分析后的数据直接公开。这意味着任何人都可以在这个基础上继续做：按自己的兴趣再过滤一遍；做成桌面客户端或 Android TV 应用（已经有人做了）；接入自己的知识库，做成更私人的推荐引擎。

这比单纯做一个封闭网站有意思得多。

HackerTube 本身可能不会成为下一个现象级产品。它更像一面镜子，照出了两件事：

一件是，我们长期被平台推荐算法驯化后，其实已经忘记"真正好内容"是什么感觉了；

另一件是，AI 编程代理正在把"有想法就能快速验证"这件事，从极少数人的特权，慢慢变成更多人可以触碰的能力。

下次你再对着 YouTube 首页发呆，觉得怎么推的全是你不想看的东西时，可以去 https://hackertube.org/ 看看。

也许你会突然想起，原来互联网上还有一批视频，是真正被聪明人反复推荐过的。

而现在，把它们找出来，只需要一个周末，外加一次和 Claude 的认真对话。
