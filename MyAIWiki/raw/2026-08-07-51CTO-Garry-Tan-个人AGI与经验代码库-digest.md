## 一句话总结

> 个人 AGI 不在租来的模型，而在把判断、边界和验收标准沉淀成可检索、可执行、可治理的经验代码库。

## 五个核心观点

1. **差距来自上下文闭环：** 同一模型的效果取决于是否拿到正确资料、工具和历史纠正，而不只取决于模型能力。
2. **Skill 是可执行经验：** 一份 Skill 应保存输入、步骤、判断标准、禁止事项和验收证据，使经验跨会话、跨 Agent 复用。
3. **模型不替代确定性系统：** 模糊理解可交模型；金额、权限、状态和大规模约束必须交给代码、数据库、测试或规则。
4. **经验需要双重归属：** 公司保留业务秘密和内部流程；个人可积累脱敏框架、公开知识与个人复盘，不能混淆边界。
5. **记忆库需要治理：** 来源、时间、冲突、失效、权限和审计缺一不可，否则会把旧错误稳定放大。

## 7 个分析角度

### 1. 模型为何不等于生产力
- 模型相同，工作上下文不同。
- 工具相同，完成标准不同。
- 聊天记录不等于长期经验。

### 2. Skill 该保存什么
- 保存判断顺序，不只保存命令。
- 保存禁区，不只保存成功路径。
- 保存验收证据，不只保存结果。

### 3. 何时交给模型
- 偏好理解可交模型。
- 模糊归因可交模型。
- 多种合理答案可交模型。

### 4. 何时交给程序
- 金额计算交给程序。
- 权限状态交给规则。
- 大规模排期交给算法。

### 5. 如何开始积累
- 从最讨厌的重复任务开始。
- 先运行一次，再补纠错。
- 每次完成都问能否 Skill 化。

### 6. 归属如何划线
- 不复制公司代码和客户资料。
- 保留脱敏的通用方法。
- 以合同和制度判断边界。

### 7. 为什么必须治理
- 记录来源和更新时间。
- 冲突先提示，不直接覆盖。
- 高风险动作保留人工确认。

## 21 个开头钩子

### 1. 模型差距
1. 同样订阅 Claude，为什么结果能差几十倍？
2. 真正拉开差距的，往往不在模型。
3. AI 失忆一次，你就在重复教一次。

### 2. Skill 本质
1. Skill 不是提示词，是经验的可执行版本。
2. 一次排障不留文件，下一次仍从零开始。
3. Markdown 开始承载的，是工作方法。

### 3. 确定性边界
1. 判断能交给模型，算账不能。
2. 权限和库存，不该靠模型“这次大概对了”。
3. Agent 最危险的地方，是把概率当事实。

### 4. 个人 AGI
1. 模型是租来的，经验代码库才是自己的。
2. 个人 AGI 不在云端，它先在你的文件夹里。
3. 你的资料越多，越需要一个图书管理员。

### 5. 经验复利
1. 别让 Agent 只完成一次性工作。
2. 每一次纠正，都该成为下一次的起点。
3. 重复劳动的终点，是一份可验收的 Skill。

### 6. 经验归属
1. 经验可以积累，但不能把公司秘密带走。
2. 最该留下的，是脱敏后的判断框架。
3. 你教会 Agent 的东西，也该留一份给自己。

### 7. 治理边界
1. 没人维护的知识库，只是更会搜索的垃圾场。
2. 旧经验不清理，会让 Agent 更自信地犯错。
3. 记忆越集中，权限和审计越不能省。
