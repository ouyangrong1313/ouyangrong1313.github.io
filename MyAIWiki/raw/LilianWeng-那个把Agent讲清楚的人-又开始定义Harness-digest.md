## 一句话

这篇二手整理把 Lilian Weng 从 2023 年 Agent 架构综述到 2026 年 Harness/RSI 文章的脉络连起来：近期可操作的自我改进，是优化模型外的执行、状态与评测闭环，而不是直接改模型权重。

## 五个要点

1. **Agent 地图**：规划、记忆和工具调用把单次模型调用扩展成可行动的系统。
2. **Harness 边界**：Harness 编排工具、上下文、持久状态、工作流和评测，决定长任务能否恢复和迭代。
3. **优化迁移**：优化对象可从 Prompt 逐步上移到结构化上下文、工作流与 Harness 代码。
4. **RSI 闭环**：系统读取执行轨迹、修改策略，再由外部评测决定是否保留，才构成可审计的改进循环。
5. **安全外置**：可改范围、权限和验收标准不能随优化器一起修改，否则会出现 reward hacking。

## 可复用判断

- 不要把“模型会推理”误当作“任务能稳定完成”；失败恢复和验证证据属于 Harness。
- 先为真实任务建立可重放的轨迹和独立评测，再讨论自动修改工作流。
- 人的职责转向定义不可变边界、目标函数和接受标准，而非退出闭环。
