## 一句话总结

> 创业早期最大的失败模式不是选错方向，而是一直不选——"别过度思考、烧掉其他船、深到能替客户经营业务"三件套，叠加"AI 时代好想法 3 个特征"（模型能力边缘 / verticalize / 最有野心的版本），是 YC 合伙人 John 给创业方向选择的最直接框架。

## 5 条核心观点

1. **别过度思考**——完美想法不可能在抽象思考里被推导出来，只能通过接触现实验证
2. **烧掉其他船**——选一个方向就要彻底切过去（公司叙事/网站/邮件/对外表达都改），否则你得到的所有反馈都会很浅
3. **深到能替客户经营业务**——如果你明天被丢进客户公司，你能不能把他们的业务跑起来？这个标准比"和 20 个老板聊过"高得多
4. **AI 时代好想法 3 特征**：①站在模型能力边缘（解决瓶颈本身可能就成为公司）②走向 verticalize（拥有结果而非卖工具）③选择最有野心的版本（小版本和大版本成本差不多）
5. **失败也是入口**——深入一个方向后你经常会发现更好的想法；最大的失败是"一直不做判断"

## 决策树

```
有多个看起来都不错的创业想法？
├─ 你是否已经"沉进去"任何一个方向？
│   ├─ 否 → 浅反馈是误导的最大来源 → 立刻选一个
│   └─ 是 → 进入 AI 时代 3 特征判断
└─ 3 特征判断
    ├─ 是否站在模型能力边缘？（明天会被自动解决的问题不做）
    ├─ 是否能 verticalize？（能否从"卖工具"走向"拥有结果"）
    └─ 是否选了最有野心的版本？（温和版 vs 激进版成本差不多，要选激进版）
```

## 5 关键金句

- "创业早期最危险的，不一定是选错方向，而是一直不真正选择。"
- "你不需要一开始就是这个领域最资深的人……很多创业机会，不是留给'已经被授权的人'的，而是留给'愿意扎进去的人'的。"
- "创业不是先研究完，再开始做。创业是研究和交付不断互相推进。"
- "活在未来，然后把缺失的东西做出来。"（呼应 Paul Graham）
- "创业最糟糕的失败模式，不是判断错了。而是一直不做判断。"
