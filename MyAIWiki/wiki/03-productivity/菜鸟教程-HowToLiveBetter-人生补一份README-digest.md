## 一句话总结

工作有 README，人生也该有一份——把健康、租房、维权、学习这类"吃亏才补课"的常识，做成按性价比排序、遇事能查的清单。

## 速查表

| 维度 | 要点 |
|---|---|
| 核心问题 | 常识缺口：会学工作，不会照顾自己、处理生活麻烦 |
| 失败模式 | "等以后"——感慨完又回到熟悉节奏 |
| 解法 | 人生 README：遇事知道先查什么、从哪里下手 |
| 关键设计 | 按性价比从高到低排序 |
| 参考项目 | HowToLiveBetter（614 条 / 33 文件）、byoungd/up（五环节方法论） |
| 技术形态 | 纯静态，克隆即用，无后端/数据库/依赖 |

**核心金句**：代码有 README，人生好像也该补一份。

## 反直觉点

1. **感慨≠改变**：每次看到消息都提醒自己要改，但过几天回到原样——情绪不解决问题，清单才能。
2. **"读全"不是目标**：清单的价值在"降到事上时能查到"，不在于背下来。
3. **排序比内容重要**：同样的建议，按性价比排序后，投入产出比完全不同。

## 对 Seetong 可借鉴动作

- 建一份"团队 README"：反复踩的常识（环境/发布/权限/回滚）做成遇事速查，按"踩坑频率 × 修复成本"排序。
- 清单化优先于文档化：每个坑一行"现象 → 先查什么 → 怎么下手"。
- 先做最高频 5 个坑，验证"真会去查"再扩。
