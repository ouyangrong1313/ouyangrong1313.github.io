为什么越来越多的顶级领导者，开始认真学哲学？

  • 原文链接：https://mp.weixin.qq.com/s/AKjTaww6Xfen7ytFaAyg8A
  • 原作者：Faisal Hoque + Paul Scade + Pranay Sanklecha + Sverre Spoelstra
  • 来源：哈佛商业评论（Harvard Business Review 中文版 / HBR-China）2026-07-01
  • 编校：周强
  • 获取时间：2026-07-01 10:24 Asia/Shanghai

核心结论（一句话）

AI 时代的竞争不只是模型能力的竞争，也是价值判断的竞争——哲学素养正像财务素养一样，成为现代领导者不可或缺的核心能力。本体论（企业目的 / 客户数据本质）+ 认识论（怎么知道是真是假）+ 伦理学（10% 收入损失测试）三大领域构成”哲学决策”基本功，最终落地为”phronesis 实践智慧”——只能通过处理真实案例的经验发展。

知识节点（8 个独立概念）

分类：AI 时代领导者哲学决策 / 价值判断方法论 / 个人领导力素养

  1. AI时代竞争-模型能力加价值判断：Google DeepMind 设立”哲学家”岗位（剑桥大学 Henry Shevlin 加入）；Anthropic 把牛津哲学博士 Amanda Askell 编入核心团队构建 Claude”宪法”；30 万家企业部署 Claude（含美十大公司 8 家）。哲学素养 = 发现、质疑和思考那些左右决策的基本假设的能力，正变得和财务素养一样成为有效领导的关键能力。
  2. 本体论-企业目的Friedman-vs-Drucker：企业的目的是什么——这是本体论最根本的问题之一。米尔顿·弗里德曼：”股东回报最大化”（引导战略 / 文化 / 业务流程的下游决策）；彼得·德鲁克：”人们组织集体生活的社会机构”（一套完全不同的优先级）。大多数领导者从未有意识地在这类观点之间做出选择——决策是基于未经审视的默认假设做出的。
  3. 苹果客户数据本体论-你不是我们的产品：蒂姆·库克将隐私视为”基本人权”，围绕”客户数据是与客户关系的数字化体现，是托付给公司的，客户在其中仍保有权益”构建战略。”你不是我们的产品，你是我的客户“——这一底层假设不仅影响数据政策，还塑造产品设计 / 商业模式 / 公司员工用户如何看待自身。客户数据是什么已成为当代商业中最重要的本体论问题之一。
  4. 认识论-丰田现地现物：丰田长期奉行的”现地现物”原则（亲自去看看）——是正式认识论规范。与物理现实的直接经验性接触，是比远程收集和推理的信息更可靠的判断基础。理解问题的最佳方式是领导者亲自去到问题存在的地方，直接面对它。
  5. 认识论-Tonys-Chocolonely五项采购原则：荷兰巧克力公司 Tony’s Chocolonely（2005 成立）针对可可供应链童工/奴隶制问题，制定五项采购原则：任何知识主张都必须有依据、经得起反复推敲，并且要根据公司目前能了解到什么程度、以及在实际操作中能达到多高的准确度来检验。建立”比含糊其辞的说法或仅仅依赖认证更严格的道德采购标准”。
  6. 伦理学-Anthropic-20262-vs-五角大楼：2026 年 2 月五角大楼最后通牒——Anthropic 接受”任何合法用途”合同条款，否则失去合同。Anthropic 坚持两项限制（不用于大规模国内监控 + 不用于完全自主武器），五角大楼终止合作转投竞争对手。Anthropic 清楚其伦理承诺的具体边界，能够阐明这些承诺为何存在，并以重大的商业代价坚守了它们。这是 AI 公司伦理一致性的对比鲜明案例。
  7. 伦理学-10-收入损失测试：3 步骤伦理素养自测——找出公司 3 个伦理立场 → 对每一个问”如果这会让我们损失 10% 的收入，我们还会坚持这个立场吗” → 答案否的话不是真实伦理承诺，要么是营销噱头要么是领导层遮羞布。能分清这两者，是伦理素养的第一步。能讲清楚为什么坚守并且在别人咄咄逼问时还能站得住脚，是下一步。
  8. phronesis-实践智慧：亚里士多德区分”理论知识”（可从教科书学）与“phronesis 实践智慧”（只能通过处理真实案例的经验发展）。实践智慧不光是一门能用上的手艺，更是一种得慢慢修出来的品性。”如同任何需要练习的能力一样，如果不加以运用，它就会衰退”——”工具 1 制造有益的碰撞”+”工具 2 追踪哲学偏离”是 phronesis 的具体载体。

6 个对 Seetong 团队可借鉴动作

  1. 本体论体检：主人 / 黄松佳 / Seetong 团队写下 3 个根本问题的定义 —— “Seetong 的目的是什么”（用户安全 / 监控效率 / 设备销量？）”客户数据是什么”（监控数据是公司资产还是用户托付？）”AI 摄像头是什么”（工具 / 助手 / 监控代理？）。答案的分歧之处 = 团队在本体论上的不一致，下一步努力达成共识。
  2. Seetong 客户数据本体论明确化：是用户活动产生的原材料（变现）还是客户关系的数字化体现（保护）？Seetong AI 助手需要明确这个根本立场 —— 决定数据保留 / 第三方分享 / 模型训练用法的产品决策方向。
  3. 认识论实践-回顾 Seetong 决策：Seetong 团队每月例会增加“上次最差决策 + 上次最好决策”复盘 —— 当时相信了什么 → 那个信念从哪来。如果没人说得清这个信念的源头，那它就从来没有被好好地论证过——参考丰田”现地现物”，主人 / 黄松佳要亲自去客户现场看，而不是依赖报告。
  4. Anthropic 对齐-伦理立场预案：当 Seetong 客户 / 合作方要求”任何合法用途”时（如 4G IPC 设备被用于监视特定人群 / 远程开门被用于偷盗 / 设备数据被用于歧视性定价），Seetong 是否敢于坚守伦理边界？—— 主人需要提前想清楚，参考 Anthropic 2026.2 拒绝五角大楼的勇气与商业代价。
  5. 10% 收入损失测试：Seetong 团队找出 3 个伦理立场（如”不收集 0-13 岁儿童数据”/”设备不被用于私人监视”/”不接入未经审核的第三方 SDK”），问”会损失 10% 收入还坚持吗”——区分”真承诺”vs”营销噱头”。答案否的话要么是营销噱头要么是领导层遮羞布。
  6. AI 工具哲学假设季度审查：Seetong AI 助手 / Codex / 第三方 SDK —— 主人每季度问”这些工具带了什么哲学假设进入 Seetong”，与 Seetong 自身假设是否一致。参考”工具 2 追踪哲学偏离”——市场变化 / 社会演进 / 技术进步会持续将嵌入系统中的假设拉离组织原有信念。

备注与限制

  • 作者全部为外部专家：4 位作者都在哲学与领导力交叉领域，非 AI 公司内部视角。结论是”哲学素养重要”的一般性主张，但缺少 AI 公司内部的实证案例（除了 Anthropic / DeepMind 的角色设置）。
  • Anthropic 案例时效性：2026.2 五角大楼合同对峙是 5 个月前事件，当前 Anthropic 的伦理一致性是否依然成立需要持续追踪。原文作者也明确说”Anthropic 在伦理一致性方面的整体记录并非无可指摘”。
  • 工具的可操作性：工具 1 + 工具 2 给出了方法论框架，但缺少具体落地动作的细节。Seetong 借鉴时需要把”哲学假设说明”和”AI 工具审查表”细化成可填写的文档模板。
  • “哲学”概念过载：本文中”哲学”既指严格意义的哲学学科（本体论 / 认识论 / 伦理学），也泛指”对根本假设的反思”——Seetong 团队理解时要避免”把普通决策哲学化”。日常运营决策不需要上升到本体论，只有当决策涉及”事物本质”或”根本立场”时才需要。
  • 10% 收入损失测试的局限：3 个立场太简略，实际公司可能有 10+ 个伦理立场。建议 Seetong 借鉴时扩展为”3 个核心立场 + 7 个次要立场”分级评估。
  • 跨文化适用性：本文 4 位作者 3 位欧美 1 位印度，案例几乎全在美国 / 欧洲。Seetong 作为中国公司借鉴时需要考虑”言论 / 隐私 / 监控”等议题在中国市场的本地化语境。
