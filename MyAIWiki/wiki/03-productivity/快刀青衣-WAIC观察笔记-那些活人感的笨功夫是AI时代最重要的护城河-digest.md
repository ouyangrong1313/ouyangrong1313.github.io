# WAIC 观察笔记：那些活人感的笨功夫（Digest）

> **来源**：微信公众号「快刀青衣」2026-07 推送（WAIC 2026 观察笔记最后一期 / 原文 https://mp.weixin.qq.com/s/-QmSX3jEbQ3uaVvXEWgdfA）

## 一句话总结 + 核心金句

> **AI 不是先替代一个人，而是先拆开一份工作**：4 大趋势（共同基础设施 / 评价尺子变稳定 / 一块块接走 / 长出新任务）+ 能力鸿沟 + 3 类动作自检 + 笨功夫护城河。AI 跑得越快，笨功夫越贵。

1. **"AI 不是先替代一个人，而是先拆开一份工作。"**
2. **"AI 进步得特别快，但现实世界改造得特别慢。"**
3. **"AI 偶尔做出一张惊艳的 90 分图片，和每天稳定交付一百张能用的 75 分图片，这可不是同一个能力。"**
4. **"表面上看两个人都在用 AI，真正形成的能力差距可能已经不在同一个量级。"**
5. **"AI 跑得越快，我觉得咱们的笨功夫越贵。"**

## 4 大趋势 + 9 节点速查

| # | 节点 | 一句话 |
|---|------|--------|
| 1 | AI 成为共同基础设施 | 瑞幸/伊利/电网/气象局都来 → 每家公司都是 AI 公司 |
| 2 | 评价尺子变稳定 | 从"模型多大"到"能不能稳定把活干完"，WAIC 大模型 18:Agent 65 ≈ 1:3.6 |
| 3 | AI 把工作拆开接走 | 不是替代职业，工程师 60→2 天 / 货代 2 月→2 分钟 / 医生病历口述 |
| 4 | 工作拆开长新任务 | 灵初智能：数据采集师 + 数据审核师（手稳的人反而适合） |
| 5 | 能力鸿沟 | 联合国 7/19 论坛：制度 + 技能 + 基础设施 + 专业知识 4 要素差距 |
| 6 | 3 类动作自检 | 重复动作（交 AI）/ 专业判断（AI 参考）/ 关系信任（必自己） |
| 7 | 笨功夫护城河 | 5 类：行业理解 + 现场经验 + 客户信任 + 失败复盘 + 数据洞察组织化 |
| 8 | 我是执行还是定义任务 | 工作拆开后**人**的位置从"执行"转为"定义" |
| 9 | 现实世界改造特别慢 | 物理世界 + 法律责任 + 安全制度 → 机器人先接手固定环境 + 重复动作 + 高危 |

## 关键参数速查

- **65 : 18 ≈ 3.6 : 1** — WAIC 2026 Agent/智能应用 vs 基础大模型企业比例
- **60 天 → 2-3 天** — 工程师配方
- **2 月培训 + 2 小时/单 → 2 分钟/单** — 货代报价
- **2 个新岗位** — 数据采集师 + 数据审核师（灵初智能）
- **4 要素** — 能力鸿沟：制度 + 技能 + 基础设施 + 专业知识

## 反直觉点 3 条

1. **问题问错了**：原问"哪些工作会消失"应改为"我是执行动作还是定义任务"
2. **能力鸿沟不在一个量级**：同样 AI 工具，不同接法 → 能力差距爆炸
3. **笨功夫是最大护城河**：AI 跑得越快，活人感的笨功夫越贵
