# Garry Tan 个人 AGI 与经验代码库 - Digest

## 一句话

> 最可复利的 AI 资产不是模型订阅，而是把重复工作的判断、禁区和验收标准写成可检索、可执行、可治理的经验代码库。

## 8 节点速查

| 节点 | 记住什么 |
| --- | --- |
| 经验代码库 | 保存经验的可版本化资产 |
| Skill化 | 输入、步骤、禁区、证据齐全 |
| 上下文检索 | 按任务取资料，不整库塞入 |
| 确定性边界 | 计算、权限、状态交给程序 |
| 一次性工作 | 不沉淀过程就会重复解释 |
| 个人经验归属 | 脱敏方法可积累，秘密不可带走 |
| 知识库治理 | 来源、时间、冲突、失效可追溯 |
| 权限与审计 | 最小权限，高风险人工确认 |

## 五个落地动作

1. 选一个每周重复的任务，先在一次真实执行后写成 Skill。
2. 每份 Skill 固定写触发、输入、步骤、禁止、输出、验证和升级条件。
3. 用“答案是否允许不同”判断模型与代码的边界。
4. 将个人复盘与公司受控知识分库存放，禁止混入客户数据、密钥和内部流程。
5. 每月检查 Skill 的来源、最近验证时间、失效条件和权限级别。
