## 3 个反直觉点

- **Agent 不是替代 CRM/ERP,而是在中间新增"认知与行动层"** —— 多数企业误解为"Agent = 替代业务系统",实际是中间层
- **Coding Agent 不是"恰好 AI Coding 火"**,而是 4 个天然条件(上下文/工具/验证/恢复)叠加 —— 这套条件在金融/法律/医疗等专业领域不具备,所以 Coding Agent 优先跑通
- **AI 原生组织不是"用 AI 的组织",而是"为 AI 重构流程的组织"** —— 不是现有流程叠加 AI,而是流程重构 + 岗位重定义 + 评价体系重构
