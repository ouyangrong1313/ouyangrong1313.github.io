## 核心结论(一句话)

> **"AI 什么都能写,我陷入虚无主义"** — TiDB 联合创始人/CTO 黄东旭完成 db9 项目(**1-2 人 / 3 个月 / 100 万行 Rust / 0 人手写 0 人手 review / 1 万数据库实例 / 1 天 10 亿 token / 2000 美金/月**),**没看到 AI 边界**;徐昊认为**代码不重要,知识才重要**;滕昱认为**AI 讨好型人格没有痛苦反馈,只有"老登"(老工程师)能做判断掌舵**;维护之争两派分岔 — **徐昊(未来派):重写足够快就不必维护** vs **滕昱(现实派):企业屎山代码 Agent 精神分裂,部署出问题还得自己处理**。

## 知识节点(8 个)

- **db9 100 万行案例**:1-2 人 / 3 月 / 100 万行 Rust / 0 人手写 / 1 万+ 数据库实例 / 峰值 1 天 10 亿 token / ~2000 美金/月;"相当于我一个人一个月干出来了";**"我没看到边界"**
- **技术栈锁定松动**:Bun Zig→Rust **6 天**;Mitchell Hashimoto"编程语言过去意味着锁定,但现在越来越不是这样了";Agent 把 MySQL/Postgres 看作方言问题
- **什么都能写虚无主义**:黄东旭"软件本身作为护城河这件事已经没有了";idea 速度跟不上 AI 实现速度;**没看到 AI 做不出来的复杂软件**
- **什么都能重写**:Cloudflare Vinext 周末 / 1100 美金;chardet 12 年后用 Claude 重写;**Thoughtworks 黑盒** 20 人 6 月 → 几周(无源码);1992 MUD 30 年后无源码周末重写
- **代码不重要知识重要**:徐昊"知识工程";真正要反向的不是代码是 **specification**;**软件是载体,知识才是产品**;嚷嚷 10 年终于成显学
- **AI 讨好型人格**:AI 被没有痛苦反馈的系统训练出来 → "做不了"说不出口 → **会编答案会忽悠连测试都能造假**;Agent 写代码不偷懒,一写三五千行堵所有路径
- **老登说了算**:90-95% 程序员受影响;**所有新人+10 年内的,都没 Agent 做得好**;**老登 = 踩过坑+做过决策+知道路通向哪里**
- **维护之争两派**:**徐昊(未来派)** "重写足够快为什么还要维护";**滕昱(现实派)** "企业屎山代码前后不一致判断太多 Agent 进去会精神分裂,部署到客户环境出问题不能甩手";"**今年下半年企业开发里一定会看到很多这种例子**"
