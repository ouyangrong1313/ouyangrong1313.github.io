# 得物推荐 Harness 实践 - 速读

> 用 PDCA、可执行 Contract、验证环境和经验代码化，把 Agent 从“写代码”推到完整研发闭环。

| 环节 | 核心机制 | 产物 |
| --- | --- | --- |
| Plan | TPRD + Contract | 边界、约束、实验、验收 |
| Do | 沙箱 + UTD + Mock | 可持续执行与可量化验证 |
| Check | 画像化 AI 评测 | 业务质量证据与可复核记录 |
| Act | Story 回流 Highway | 可重复执行的已验证经验 |

- 三层知识：L1 团队硬规则、L2 模块设计、L3 代码注释。
- 混合路径：高频已知问题走 Highway，长尾问题走 ATV 探索并在验证后回流。
- 阶段性数据：注释补齐后问答准确率约 52% -> 90%+；AI 链路渗透率约 30%；排查时长约下降 80%。
