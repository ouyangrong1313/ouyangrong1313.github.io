# Lilian Weng：那个把 Agent 讲清楚的人，又开始定义 Harness - 速读

> Agent 解决“能否行动”，Harness 解决“能否在真实环境中稳定完成、恢复和改进”；自动改进必须受独立评测和不可修改的安全边界约束。

- **Agent架构地图**：规划、记忆、工具调用与环境交互。
- **Harness运行系统**：上下文、状态、工作流、权限、失败恢复与评测。
- **优化对象迁移**：Prompt → 结构化上下文 → 工作流 → Harness 代码。
- **外部评测闭环**：读取轨迹、提出变更、独立验收、仅保留有效变更。
- **可编辑边界**：不让优化器同时修改测试、权限或验收标准。
- **研究品味**：弱评测和问题选择不能仅靠分数自动化。
