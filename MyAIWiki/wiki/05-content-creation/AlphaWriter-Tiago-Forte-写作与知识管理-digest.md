# Tiago Forte 写作与知识管理 - Digest

## 一句话

知识的复利来自“未来仍能理解 + 需要时逐步提炼 + 最终进入现实成果”，不是阅读量、收藏量或一次性精细分类。

## 8 节点速查

| 节点 | 一句话操作 |
| --- | --- |
| 未来自己笔记 | 每条重要笔记补上来源、标题、重点和保存理由。 |
| 渐进式总结 | 首次捕捉，重访高亮，使用时提炼。 |
| 思想群岛 | 先排列成熟想法，再写它们之间的关系。 |
| 中间成果包 | 将大作品拆成能独立复用的小交付物。 |
| Favorite Problems | 用长期问题筛选值得保留的信息。 |
| PARA 行动优先 | 让项目而非分类本身决定信息的优先级。 |
| 输入输出循环 | 以未来要写出来的标准读，主动查证和反驳。 |
| 知识复用 | 让过去的判断、案例和结构进入今天的新成果。 |

## 三个反直觉点

1. **读更多不等于积累更多。** 如果无法在项目或作品中重新调用，阅读只增加了短时接触量。
2. **完美整理常是浪费。** 第一次无法准确判断价值，整理成本应跟随重访与实际使用增加。
3. **知识库不是终点。** 分类完整却不生成文章、决策、产品或解释，仍只是材料仓库。

## 最小实践

1. 对每条要长期保留的材料，补写“为什么留下、将来可能用于什么”。
2. 保留 3 至 12 个可以持续数年的问题，用它们筛选输入。
3. 开始写作时先检索笔记，列出 5 至 15 个已有观点，再写它们之间的关系。
4. 为大任务先产出一个中间成果包，例如案例卡、图、反例清单或一页提纲。
5. 每次重用材料时只做一层额外加工，不追求一次完成所有整理。
